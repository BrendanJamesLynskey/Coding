# Coding Theory — Error Detection & Error Correction

Interactive presentation series covering the theory and practice of error-detecting and error-correcting codes, from basic parity checks through to modern capacity-approaching codes.

**[View the presentations](https://brendanjameslynskey.github.io/Coding/)**

Part of the [Mathematics & Engineering](https://brendanjameslynskey.github.io/) collection.
